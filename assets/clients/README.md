Client logos go here.

Nothing is in this folder on purpose. Permission to name a client is not
permission to use their logo: a logo is a trademark and its use implies
endorsement. Ask each client for the file and for written permission, then add
the path to that client's entry in content.js:

    logo: "assets/clients/flyability.png",

Wide files, roughly 4:1, on a transparent background work best. The site renders
them at 34px tall, left aligned, above the client name.

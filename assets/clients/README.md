Client logos.

All three current logos were supplied by the clients and cleared for use on

add one that has not been cleared the same way.

## The treatment

Each file is composited onto the same **200 by 58 canvas at 3x (600 by 174)**,
transparent, logo left aligned and vertically centred.

Inside that canvas the mark is scaled by **optical area, not by height**. A
square mark and a wide wordmark set to the same height do not look the same
size, and a logo row set that way looks uneven no matter how carefully it is
spaced. Matching the area each one covers is what makes them read as equals.
The current three land at 58x58, 79x54 and 76x56 inside the box.

Nothing is cropped into or recoloured. The marks are as supplied.

## Adding one

Put the processed file here, then add the path to that client's entry in
content.js:

    logo: "assets/clients/flyability.png",

If you drop in a raw file without the canvas treatment it will render at the
wrong size and sit heavier or lighter than the others.

## Why the home page uses names, not logos

The client row on the home page sits on the navy band. These marks are black and
red, so they would be close to invisible there, and recolouring a client's logo
to fit our palette is exactly what trademark permission does not cover.
